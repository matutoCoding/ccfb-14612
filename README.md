# 水印网模设计与抄纸成形仿真系统

面向防伪水印纸（证书纸、票据纸）的浏览器端网模设计与抄造成形仿真系统。
TypeScript + WebGL2，纯前端运行，网模/浆料/仿真/打样数据全部存 IndexedDB。

## 运行

```bash
npm install
npm run dev      # 开发服务器
npm run build    # 类型检查 + 生产构建（输出 dist/）
npm run preview  # 预览生产构建
npm test         # 核心数值管线冒烟测试（17 项）
npm run perf     # 生产规模性能计时
```

推荐使用 Chrome/Edge 等支持 WebGL2 与 `EXT_color_buffer_float` 的浏览器。

## 六大页面

| 页面 | 功能 |
| --- | --- |
| 网模设计 | 灰度图（上传或内置图案）转浮雕；分档表手改灰度→高度（μm），正=凸起白水印、负=凹下黑水印；Sobel 边缘陡度分析，>350 μm/mm 提示针眼风险；版本管理 |
| 浆料配方 | 针叶/阔叶/棉浆三配比，分浆种纤维长度、粗度，打浆度、上网浓度、流速、目标定量；对数正态混合模型程序生成纤维长度分布 |
| 抄造仿真 | 30 万纤维 GPU instanced 沉积；定量分布图、多尺度匀度曲线（对比好纸基准）、干燥收缩/水印公差、同模多浆批量对比、复现性校验、换种子偏差测试 |
| 透光观察 | 透射（Beer-Lambert 厚度衰减，水印层次分明）/反射（漫反射，水印几乎不可见）切换；光源角度、纸张翻面、PNG 导出 |
| 纸病分析 | 自动检测针眼、薄斑、絮团、水印走形，纸面圈注并按面积分 A/B/C 三级，支持类型/等级筛选 |
| 打样记录 | 绑定网模版本与浆料批次，导入实测透光照片，与仿真透光图并排对比 |

## 确定性保证（核心指标）

- 全数据管线只使用种子化 PRNG（mulberry32 + Box-Muller），**禁止 Math.random 进入仿真**
- 纤维按固定顺序生成、instanced 绘制顺序固定、加法混合与顺序无关
- 同网模 + 同浆料 + 同随机种子 → 定量场逐位一致，数据指纹（FNV-1a 浮点字节哈希）相同
- 总质量按目标定量二次归一化，**换种子平均定量偏差为 0**（要求 ≤1%）
- 页面内置「复现性校验」（两次指纹比对）和「换种子偏差测试」（5 种子统计）

## 性能

- 默认 A4 仿真网格 840×1188（0.25 mm/px）、30 万纤维，纤维打包 8 float/根
- 纤维生成（CPU）约 0.3 s、纸面分析约 0.3 s，GPU splat 在独显/集显上为亚秒级
- 分析网格为仿真网格的 2×2 降采样（约 0.5 mm/px，对应定量仪采样尺度）
- 注：无独显的纯软件渲染（SwiftShader）会明显变慢，真机 GPU 满足 30 秒预算

## 物理模型要点

- **纤维沉积**：包裹正态取向往纵向（MD）集中；浮雕边缘纤维沿等高线偏转（slope/350 混合）
- **絮聚场**：粗网格值噪声 + 平滑 + MD 拉伸，幅度挂钩上网浓度、拉伸挂钩流速
- **浮雕脱水**：凸起处 `retention = 1 - 0.5·h_n`，脱水快、留着薄，形成白水印
- **高斯 splat**：纤维束横向高斯软覆盖，加法混合累积定量/厚度双通道（MRT）
- **匀度**：积分图多尺度盒滤波求各尺度 CV%，FI 按 4 mm 尺度标定
- **干燥收缩**：MD/CD 分开，随打浆度与棉浆比例上升，水印尺寸变化超公差标红
- **透光**：透射 `exp(-光学厚度·光程)`，反射仅保留 3.5% 浮雕可见度

## 目录结构

```
src/
  lib/
    rng.ts          确定性 PRNG、种子哈希、数据指纹
    types.ts        数据模型与 IndexedDB 文档结构
    db.ts           IndexedDB 五张表封装
    mold.ts         灰度转浮雕、分档插值、Sobel 针眼风险
    furnish.ts      浆料模型、纤维长度对数正态分布
    deposition.ts   纤维生成、絮聚场、浮雕导向（CPU 确定性）
    gl-engine.ts    WebGL2 instanced splat + 观察着色器
    analysis.ts     匀度、纸病连通域、收缩、清晰度
    simulation.ts   仿真编排、归一化、降采样、指纹
  pages/            六个页面
  main.ts           路由与应用外壳
test/               Node 数值冒烟测试（不依赖 GL）
```
