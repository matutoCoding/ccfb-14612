# 水印网模设计与抄纸成形仿真系统

浏览器端的防伪水印纸网模设计、浆料配方管理与抄造成形仿真工具。纯 TypeScript + WebGL2 + IndexedDB，零运行时第三方依赖，所有数据本地存储、所有计算本地完成。

## 运行

```bash
npm install
npm run dev        # 开发服务器（默认 http://localhost:5180）
npm run build      # 类型检查 + 生产构建到 dist/
npm run preview    # 预览生产构建
```

浏览器要求：支持 WebGL2 与 `EXT_color_buffer_float`（Chrome/Edge 90+、Firefox 90+）。

## 六大功能页

| 页面 | 能力 |
|---|---|
| 网模设计 | 灰度图（PNG/JPG 或内置徽章图案）转浮雕高度场；凸起=白水印、凹下=黑水印；五档高度可手改；陡边自动检测针眼风险并在预览上圈出 |
| 浆料配方 | 针叶/阔叶/棉浆三组元分别设配比、纤维长度、粗度、打浆度；长度分布按截断对数正态程序生成；上网浓度/流速/絮聚系数联动，实时出长度直方图与絮聚扫描曲线 |
| 抄造仿真 | 几十万根纤维 GPU 实例化沉积；浮雕高处脱水快沉积薄；絮聚随浓度/流速/打浆联动；浮雕边缘纤维沿梯度切线带偏；出定量分布图、多尺度波动曲线（对比好纸基准）、干燥收缩与水印尺寸漂移公差判定；支持同网模多浆料批量对比 |
| 透光观察 | 透射光（Beer-Lambert 厚度衰减，水印层次分明）/反射光（漫反射为主，水印几乎不可见）切换；光源角度、纸张翻面可调；可导出 PNG |
| 纸病分析 | 统计阈值 + 连通域自动识别针眼、薄斑、絮团、水印走形；纸面分布图上圈出；按等效面积分轻微/中等/严重三级；支持类型筛选与明细定位 |
| 打样记录 | 绑定网模版本与浆料批次；实拍透光照片与仿真透光图并排比对；放大对比模态；记录持久化 |

## 核心架构

```
src/
├── sim/
│   ├── rng.ts          确定性 PRNG（PCG + SplitMix），同种子全链路逐位可复现
│   ├── mold.ts         灰度→浮雕分档映射、盒式模糊、针眼陡边检测
│   ├── pulp.ts         配比对角混合、对数正态纤维群体、絮聚系数模型
│   ├── shaders.ts      沉积/归一化/可视化 GLSL ES 3.00 着色器
│   ├── gpuEngine.ts    WebGL2 实例化飞溅沉积、浮点纹理 FBO、运行时能力探测
│   ├── analysis.ts     匀度指数、多尺度方差、连通域纸病、干燥收缩、清晰度
│   └── orchestrator.ts 仿真编排，串起 GPU 沉积与 CPU 分析
├── pages/              六个哈希路由页面
├── db.ts               IndexedDB 封装（元数据 + 大 Float32Array 分块 blob）
├── state.ts            跨页内存状态
└── ui/                 零依赖 DOM 工具与 canvas 图表
```

### 关键设计决策

- **可复现性**：纤维位置、长度、取向全部来自种子化 PRNG，无 `Math.random` 参与仿真；GPU 沉积后做严格二次归一，使全场平均定量恒等于目标值。同网模/同浆料/同种子两次运行的厚度场逐位一致（已验证 579,840 值零差异）；换种子平均定量偏差 0.000%（要求 ≤1%）。
- **GPU 沉积**：每根纤维是一个实例化椭圆飞溅片元，加性混合累加质量/覆盖率；归一化 pass 按覆盖率消歧、叠加絮聚噪声场与浮雕脱水调制。A4 幅面 36 万纤维在软件渲染（SwiftShader）下约 3–4 秒，真机 GPU 更快，远低于 30 秒目标。
- **浮点纹理兼容**：构造时运行时探测 `OES_texture_float_linear` 是否真正可采样——部分软件渲染声明支持但 LINEAR 过滤静默返回 0，探测失败自动回退 NEAREST。
- **取向场**：GPU 加性混合在个别软件渲染上对纹理 b/a 通道写入不可靠，故取向由 CPU 用同一份确定性纤维 pose 累加，与 GPU 输入严格一致。
- **IndexedDB**：四个业务对象库存元数据，大 Float32Array 厚度场/浮雕场单独存 blob store，避免主记录膨胀。

## 物理模型简化说明

本系统是工程决策辅助仿真，不是分子级 CFD：纤维以统计群体（对数正态长度、冯·米塞斯取向、配比对角混合）表达；絮聚用相干分形噪声场建模，幅度由浓度/流速/打浆推导的絮聚系数驱动；透光用 Beer-Lambert 指数衰减；干燥收缩为打浆度与棉浆比例的经验回归。模型参数（浮雕调制限幅、絮聚增益、纸病阈值等）集中在着色器与 `analysis.ts`，可按实物打样数据标定。
